# На Крыше · приложение для ТВ-приставки (Android TV)

Оболочка для ТВ-страницы `na-kryishe-tv`: открывается на весь экран, не даёт экрану гаснуть, запускается само при включении,
при пропаже интернета показывает заставку и сама переподключается. Что показывать на экране (приветствие, афиша, фон, сезоны),
по-прежнему решается в Jarvis — приложение переустанавливать для этого не нужно.

Версия 1.1: **панель плиток приложений** (Okko, ivi, YouTube и любые другие) и возможность сделать приложение **главным экраном** телевизора.

## 1. Собрать приложение (один раз)

1. На GitHub создайте репозиторий **na-kryishe-tv-android** (Public).
2. Загрузите в него всё содержимое этой папки: **Add file → Upload files**, перетащите файлы и папки (в том числе папку `.github` — в ней автосборка).
   Если папка `.github` не загрузилась, создайте файл **Add file → Create new file**, назовите его `.github/workflows/build.yml` и вставьте туда текст из этого файла.
3. Откройте вкладку **Actions**. Если GitHub просит включить Actions — включите. Сборка займёт 5–8 минут; успех — зелёная галочка.
4. Готовый файл лежит по постоянной ссылке (она не меняется при обновлениях):
   `https://github.com/TimurAleroy/na-kryishe-tv-android/releases/latest/download/na-kryishe-tv.apk`

## 2. Поставить на приставку

Любой из способов:
- **Downloader** (бесплатное приложение из Google Play): установите на приставке, откройте, введите ссылку из пункта 1.4, скачайте и установите. Если спросит, разрешите Downloader «установку из неизвестных источников».
- **Флешка**: скачайте файл на компьютер, скопируйте на флешку, на приставке откройте его в файловом менеджере и установите.
- **adb** (для технарей): `adb connect <адрес приставки>` и `adb install na-kryishe-tv.apk`.

## 3. Первый запуск

1. Откройте приложение «На Крыше · ТВ». Сразу появится экран настройки с адресом вида `http://192.168.1.45:8765`.
2. На **телефоне в той же сети Wi-Fi** откройте этот адрес в браузере.
3. В Jarvis: **Сервис → ТВ-экраны →** нужная комната **→ Скопировать** (внизу «Ссылка для телевизора»). Вставьте ссылку на странице и нажмите **Сохранить**.
4. Экран на телевизоре сразу откроется. (Ссылку можно ввести и пультом в поле на экране настройки, но она длинная.)

Для каждой комнаты ставится своя приставка со своей ссылкой.

## 4. Автозапуск после включения

На экране настройки нажмите **«Разрешить автозапуск»** и включите для приложения «Поверх других окон». Проверьте: выключите приставку из розетки и включите. Экран должен открыться сам.
Если на приставке нет такого пункта: сделайте приложение главным экраном (см. пункт 6), либо поставьте киоск-браузер (например, Fully Kiosk Browser) и укажите ему ту же ссылку.

## 5. Плитки приложений (новое в 1.1)

Внизу экрана по центру по любой кнопке пульта (стрелки или «OK») появляется небольшая панель с плитками: иконки приложений Okko, ivi, YouTube и других. Она компактная и стоит у самого края экрана, чтобы закрывать как можно меньше; название приложения показывается маленькой подписью над выбранной плиткой.

- **Стрелки влево/вправо** переключают плитки (выбранная обводится медной рамкой), **«OK»** открывает приложение, **«Назад»** или стрелка вверх убирают панель. Если ничего не нажимать, панель уходит сама через 15 секунд.
- **Какие приложения показывать.** Откройте экран настройки (кнопка «Меню» или долгое «OK»), а на телефоне — показанный на нём адрес (как в пункте 3). Ниже поля для ссылки раздел **«Плитки приложений»**: список всех приложений приставки. Отметьте нужные галочкой, расставьте порядок стрелками ▲▼ и нажмите **«Сохранить плитки»**. Кнопка **«Вернуть стандартные»** возвращает Okko, ivi и YouTube.
- Пока вы ничего не меняли, показываются Okko, ivi и YouTube — те из них, что установлены на этой приставке. Чего на приставке нет, того на панели нет.
- **Приложение должно быть установлено на приставке** (из Google Play приставки) и один раз выполнен вход в аккаунт заведения. Установить его удалённо из Jarvis нельзя.
- Плиток не больше 8. Настройка плиток хранится на самой приставке, у каждой комнаты свои.

## 6. Главный экран (новое в 1.1)

Приложение можно сделать главным экраном телевизора: тогда после включения и по кнопке «Домой» всегда открывается наш экран, а не стандартный.

1. Нажмите на пульте «Домой» (на некоторых приставках Android сам спросит, какой экран использовать: выберите «На Крыше · ТВ» и «Всегда»).
2. Если не спросил: в настройках Android найдите «Приложения → Приложения по умолчанию → Главный экран» (название зависит от приставки) и выберите «На Крыше · ТВ».

**Если «Домой» всё равно открывает стандартный экран Google TV** — на приставках с Google TV его можно отключить командой с компьютера (приставка и компьютер в одной сети, на приставке включена «Отладка по сети» / ADB):

```
adb connect <адрес приставки>
adb shell pm disable-user --user 0 com.google.android.tvlauncher
```

Вернуть обратно: `adb shell pm enable com.google.android.tvlauncher`. Это необязательно, делайте только если нужно, и после обновления Google TV проверяйте, что всё осталось как было.

**Если что-то пошло не так и приставка «застряла»:** удалите приложение (Настройки → Приложения → «На Крыше · ТВ» → Удалить) — приставка вернётся к стандартному экрану.

## 7. Как управлять

- **Любая стрелка или «OK»** — показать плитки приложений.
- **Меню** на пульте (кнопка ≡) или **долгое нажатие «OK»** — открыть настройку.
- **Домой** — если приложение выбрано главным экраном, возвращает на наш экран; иначе выходит из приложения. Кнопка «Назад» экран не закрывает.
- Раз в сутки около 5 утра страница перезагружается сама, чтобы экран работал неделями без сбоев.

## 8. Обновление

Загрузите новые файлы в репозиторий — сборка пересоберётся сама, ссылка из пункта 1.4 та же. Установите новый файл поверх старого: настройки (ссылка комнаты и выбранные плитки) сохранятся.

**Один раз при переходе на версию 1.1.** Старые сборки подписывались каждый раз новым ключом, а в версии 1.1 ключ постоянный (файл `app/debug.keystore`). Поэтому, если на приставке уже стоит старая версия, Android откажется ставить 1.1 поверх («приложение не установлено» или конфликт пакетов). Один раз удалите старое: Настройки → Приложения → «На Крыше · ТВ» → Удалить, поставьте 1.1 и заново вставьте ссылку комнаты (пункт 3). Дальше обновления ставятся поверх без потери настроек.

Ключ лежит в публичном репозитории (как стандартный отладочный ключ Android): подпись нужна, чтобы обновления ставились поверх, а не как защита. Поставить приложение на приставку всё равно можно только физически или по отладке.

## Если что-то не так

- **Белый экран или надпись про WebView** — на приставке нет или устарел «Android System WebView»: обновите его в Google Play.
- **Видео тормозит** — в Jarvis уменьшите размытие фона для этой комнаты (размытие сильно нагружает слабые приставки).
- **Плитки не появляются** — на приставке не установлены Okko, ivi и YouTube (откройте раздел «Плитки приложений» на странице настройки и выберите то, что есть), либо плитки выключены (сохранён пустой список): нажмите «Вернуть стандартные».
- **Плитка не открывает приложение** — приложение удалили или у него нет окна запуска для ТВ; выберите другое.
- **Сборка красная** — откройте её во вкладке Actions и пришлите мне текст ошибки.
