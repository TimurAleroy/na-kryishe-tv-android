# На Крыше · приложение для ТВ-приставки (Android TV)

Оболочка для ТВ-страницы `na-kryishe-tv`: открывается на весь экран, не даёт экрану гаснуть, запускается само при включении,
при пропаже интернета показывает заставку и сама переподключается. Что показывать на экране (приветствие, афиша, фон, сезоны),
по-прежнему решается в Jarvis — приложение переустанавливать для этого не нужно.

## 1. Собрать приложение (один раз)

1. На GitHub создайте репозиторий **na-kryishe-tv-android** (Public).
2. Загрузите в него всё содержимое этой папки: **Add file → Upload files**, перетащите файлы и папки (в том числе папку `.github` — в ней автосборка).
   Если папка `.github` не загрузилась, создайте файл **Add file → Create new file**, назовите его `.github/workflows/build.yml` и вставьте туда текст из этого файла.
3. Откройте вкладку **Actions**. Если GitHub просит включить Actions — включите. Сборка займёт 5–8 минут; успех — зелёная галочка.
4. Готовый файл лежит по постоянной ссылке (она не меняется при обновлениях):
   `https://github.com/TimurAleroy/na-kryishe-tv-android/releases/latest/download/na-kryishe-tv.apk`

## 2. Поставить на приставку

Любой из способов:
- **Downloader** (бесплатное приложение из Google Play): установите на приставке, откройте, введите ссылку из пункта 1.4, скачайте и установите. Если спросит, разрешите Downloader «установку из неизвестных источников».
- **Флешка**: скачайте файл на компьютер, скопируйте на флешку, на приставке откройте его в файловом менеджере и установите.
- **adb** (для технарей): `adb connect <адрес приставки>` и `adb install na-kryishe-tv.apk`.

## 3. Первый запуск

1. Откройте приложение «На Крыше · ТВ». Сразу появится экран настройки с адресом вида `http://192.168.1.45:8765`.
2. На **телефоне в той же сети Wi-Fi** откройте этот адрес в браузере.
3. В Jarvis: **Сервис → ТВ-экраны →** нужная комната **→ Скопировать** (внизу «Ссылка для телевизора»). Вставьте ссылку на странице и нажмите **Сохранить**.
4. Экран на телевизоре сразу откроется. (Ссылку можно ввести и пультом в поле на экране настройки, но она длинная.)

Для каждой комнаты ставится своя приставка со своей ссылкой.

## 4. Автозапуск после включения

На экране настройки нажмите **«Разрешить автозапуск»** и включите для приложения «Поверх других окон». Проверьте: выключите приставку из розетки и включите. Экран должен открыться сам.
Если на приставке нет такого пункта: в настройках Android найдите «Главный экран / Приложение по умолчанию» и выберите это приложение, либо поставьте киоск-браузер (например, Fully Kiosk Browser) и укажите ему ту же ссылку.

## 5. Как управлять

- **Меню** на пульте (кнопка ≡) или **долгое нажатие «OK»** — открыть настройку.
- **Домой** — выйти из приложения (кнопка «Назад» намеренно ничего не делает).
- Раз в сутки около 5 утра страница перезагружается сама, чтобы экран работал неделями без сбоев.

## 6. Обновление

Загрузите новые файлы в репозиторий — сборка пересоберётся сама, ссылка из пункта 1.4 та же. Установите новый файл поверх старого (настройки сохранятся).

## Если что-то не так

- **Белый экран или надпись про WebView** — на приставке нет или устарел «Android System WebView»: обновите его в Google Play.
- **Видео тормозит** — в Jarvis уменьшите размытие фона для этой комнаты (размытие сильно нагружает слабые приставки).
- **Сборка красная** — откройте её во вкладке Actions и пришлите мне текст ошибки.
